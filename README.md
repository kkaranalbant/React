# ⚛️ React Learning Projects

A collection of **15+ React.js projects** built while learning modern frontend development with TypeScript.

## 📚 Projects

| Project | Description | Key Concepts |
|---------|-------------|---------------|
| `redux-toolkit` | State management demo | Redux Toolkit, Slices, Store |
| `anonymousarticlerevisionsystem` | Article revision system | Full CRUD, Authentication |
| `axios-deneme` | API integration practice | Axios, REST APIs |
| `doviz-kuru` | Currency exchange rates | API consumption, Real-time data |
| `login` | Authentication flow | Forms, JWT, Protected routes |
| `my-courses` | Course management app | Component composition |
| `todo` | Todo application | State management, CRUD |
| `wordmines` | Word puzzle game (v1-v4) | Iterative development, Game logic |
| `components` | Component patterns | Props, Composition |
| `use-state` | useState hook examples | React Hooks |
| `use-effect` | useEffect hook examples | Side effects, Lifecycle |
| `props` | Props & data flow | Parent-child communication |

## 🛠️ Tech Stack
- **React.js** with TypeScript
- **Redux Toolkit** for state management
- **Axios** for HTTP requests
- **React Router** for navigation
- **CSS Modules** for styling

## 📦 Getting Started

Each project is self-contained. To run any project:

```bash
cd <project-name>
npm install
npm start
```
